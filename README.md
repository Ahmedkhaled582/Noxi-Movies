**Noxi Movies** is a fully responsive, dynamic movie exploration app. Users can search, browse, and view detailed information about popular movies fetched from a public API. The interface is clean, fast, and powered by React with Bootstrap styling.

## 🧠 Project Overview
This project demonstrates a real-world front-end application with:
- Interactive API integration for fetching movie data
- Real-time search functionality
- Reusable, component-based UI
- Responsive and accessible design

## 🎯 Core Features
- 🔍 Real-time movie search by keyword
- 🧾 Movie details including rating, overview, and release date
- 🖼️ Poster display with smooth loading
- ⚡ Fast and interactive UI powered by React
- 📱 Fully responsive on all devices
- 💡 Intuitive UX with Bootstrap design

## 📦 How It Works
- Fetch API retrieves movie data dynamically
- Components handle data rendering and UI updates
- Loading and error states handled gracefully
- Search input updates results instantly

## 🛠️ Tech Stack
Technology | Purpose
-----------|---------
React.js | UI & component architecture
React Hooks | State management & lifecycle
Bootstrap | Styling & responsive layout
Fetch API | Fetching movie data
